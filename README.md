# Gestión de Tareas con Servlets

Aplicación web desarrollada con Java, Jakarta Servlet, JSP y JSTL.

## Requisitos

- JDK 17+
- Apache Tomcat 10+
- Maven 3.8+

## Ejecución

1. Clonar repositorio.
2. Abrir en IntelliJ IDEA.
3. Ejecutar:

mvn clean package

4. Desplegar el archivo WAR en Tomcat.
5. Acceder a:

http://localhost:8080/GestionTareas/tareas

## Funcionalidades

- Listar tareas.
- Agregar tareas.
- Eliminar tareas.
- Validación de campos.
- Patrón Post/Redirect/Get.
